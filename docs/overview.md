# Project Overview

*This file is a placeholder pending the full project proposal. It will be expanded with real timeline and scope details once that document is incorporated — for now it reflects only what's been confirmed so far.*

## Background

This project started from an existing spreadsheet inventory of trees and their attributes, plus one field-tested (but not yet formalized) tree collection protocol. The goal for Summer 2026 is to bring the whole system — GPS workflow, field operations, GIS structure, and public-facing map — to a standardized, documented, defensible state before fall field season.

## Objectives

See [`PROJECT_STATUS.md`](../PROJECT_STATUS.md) for the current status of each. In full, the eight objectives for this summer are:

1. GPS Accuracy Testing & Integration
2. Spatial Accuracy Finalization
3. Field Data Collection Optimization (Fall Readiness)
4. GIS Protocol Standardization
5. Web Map & Visualization Stability
6. Multi-Stakeholder Integration
7. Mentorship & Shadowing Program (Fall Launch)
8. Documentation & Knowledge Repository (this repository)

## Documentation approach

Working notes, daily logs, and in-progress drafts are kept in a private Obsidian vault. A protocol or piece of documentation only moves into this public repository once it's stable enough that someone else could follow it without the author in the room — this repo is the polished record, not the scratch pad.
