# In-Field Tree Data Collection Protocol

**Team structure:** 3–4 student volunteers plus one team leader per group. Rotate non-lead roles after each tree so everyone practices every role. Each group records 3–4 trees total per session.

## Materials needed

- Smartphone with the Arboreal Tree app
- Tree tags (at least one per volunteer)
- Hammer and nails
- Diameter measuring tape
- Water, sun protection, and a phone charger (Arboreal drains battery quickly)
- Garmin 65s GPS unit if applicaple 

## Team roles (four tasks per tree)

1. **App User** — operates the Arboreal Tree app for all digital measurements
2. **Species Identifier** — identifies the species using a plant ID app or field tool; photographs leaves/flowers/cones for later review if uncertain; verifies with a specialist if possible
3. **Tree Tagger** — finds the existing tag, or places a new one at eye level on the tree's north side if none exists
4. **Diameter Measurer** — measures trunk diameter in **inches**, just below shoulder height

*If only 3 volunteers are present:* combine Tree Tagger + Diameter Measurer into one role.

## Per-tree workflow

1. **Measure with the app** (App User completes all digital measurements -- see app steps below)
2. **Identify the species** — report the name to the App User; photograph and label with the tree's tag number if sent for further ID review
3. **Find or place the tag** — if one exists, use its number in the app and don't add a new one; if none exists, place a new tag at eye level on the north side and report the number to the App User
4. **Measure diameter** in inches at 4–5 ft height, report to the App User

## Arboreal app steps

1. Confirm GPS units are set to **meters** in app settings before starting
2. Stand within 1 m of the tree, mark it when prompted
3. Don't log GPS until accuracy is ≤5 m (see the GPS Best Practices Cheat Sheet for troubleshooting)
4. Walk backward at least half the tree's height (up to full height improves accuracy) before the height measurement prompt
5. Follow prompts for height, crown width, and crown height
6. Photograph the tree within the app, ensuring the full tree and ground are visible
7. Name the tree using the physical tag number
8. Enter the diameter measurement **in inches**
9. Enter the comment in this exact order: **Team/logger name → Species (scientific + common) → Condition (Good/Fair/Poor/Dead) → Notes** (specific: GPS issues, site conditions, anything relevant)

**Example comment:** *(Team A, LEAD). Species: Sequoia sempervirens, coast redwood. Condition: Poor. Notes: Tree appears declining; very poor GPS signal even after following cheat sheet, no sky view, cars parked near tree.*

***See 'gps_best_practices_cheatsheet' for further insight on gps accuracy pretocol during the data collection***

## End of day

1. Home screen → Results
2. Share (top right) → Export Data and Images
3. Email the exported file to the project lead
